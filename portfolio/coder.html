Página de Exemplos de Código

Breve descrição do propósito desta página

Nesta página vou apresentar exemplos de vários projectos de código, que desenvolvi ao longo da minha formação enquanto Técnico de Multimédia.

Exemplo 1 - Tabuada do número inserido pelo utilizador


Neste exercício, foi-me pedido que criasse uma página simples em HTML,
que pedisse ao utilizador um número através de um comando window-prompt e
devolvesse toda a tabuada desse número.

Exemplo 2 - Gestor de Tarefas em Python


Neste projecto, foi-me pedido que elaborasse um gestor de tarefas em Python.
O gestor de tarefas deveria permitir adicionar uma nova tarefa, consultar tarefas,
verificar tarefas pendentes, verificar tarefas concluídas, marcar uma tarefa como concluída e permitir filtros por contexto.

Exemplo 3 - Página que mostra um resumo das principais tags em HTML


Neste exemplo, desenvolvemos um conjunto de páginas que mostram em formato de texto,
um resumo das principais tags HTML utilizadas para elaborar uma página.
Criamos também uma página para mostrar um resumo das folhas de estilos (CSS).
